# Who's supporting us?

huronOS is a free software and open source project that intends to help educational institutions as well as individuals through their competitive programming competitions. This means, that huronOS does not generate any revenue, however, contributions helps to maintain the project in course and active.

Some of our supporters are:

### Instituto Politécnico Nacional
<!--[Logo of IPN Here]() -->
The National Polytechnic Institute, is a Mexican university which main focus is on engineering, maths and science. This university is supporting huronOS by providing servers to host some of the huronOS services, like the storage system for our ISO mirror servers, apt mirror, build systems, a gigabit network connection and NTP servers.

### Advanced Multi-layered Union File System (AUFS)
Junjiro Oklajima is one of the main supporters of the huronOS project by providing free maintainance of the main file system used by huronOS.

### Donors
All the Github Sponsors and donors help the project get equipment and pay bills for huronOS-related services on the cloud.
